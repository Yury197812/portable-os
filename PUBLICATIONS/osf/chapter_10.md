    Глава 10: Вычисления — Компьютеры ищут доказательства
    
    
        Вычислительная математика
        Компьютеры не просто проверяют доказательства — они их ИЩУТ. Перебор, эвристики, машинное обучение — всё это инструменты modern математика.
        
        
            Парадокс
            Задача коммивояжёра NP-трудна, но компьютеры решают её для миллионов городов. Как?
        
    
    
    
        Методы поиска
        
        1. Полный перебор
        
Время: O(n!)
Применение: Малые задачи (n 
        
        2. Жадные алгоритмы
        
Время: O(n log n)
Применение: Оптимизация, аппроксимация
Пример: Построение базиса решений
        
        
        3. Динамическое программирование
        
Время: O(n²) — O(n³)
Применение: Задачи с оптимальной подструктурой
Пример: Алгоритм Кнута-Морриса-Пратта
        
        
        4. Метаэвристики
        
Время: Зависит от параметров
Применение: NP-трудные задачи
Пример: Генетические алгоритмы, отжиг
        
    
    
    
        Вычислительные машины для задач тысячелетия
        
        Риман: Вычисление нулей
        
        Алгоритм Одлы-Шёнхаге:
        1. Вычислить ζ(s) для s = 1/2 + it
        2. Использовать формулу Римана-Зигеля
        3. Найти смены знака
        4. Проверить интервалы
        
        Результат: 10^13 нулей проверено
        Все на прямой Re(s) = 1/2
        
        
        Навье-Стокс: Численное моделирование
        
        Метод: Метод конечных разностей
        Сетка: 1024³ узлов
        Шаг по времени: Δt = 10^-6
        Время моделирования: ~1000 GPU-часов
        
        Результат: Нет сингулярностей в проверенном диапазоне
        
        
        P vs NP: Поиск алгоритмов
        
        Стратегия: Генетический алгоритм
        Фитнес: Скорость решения SAT
        Популяция: 1000 алгоритмов
        Поколения: 10000
        
        Результат: Эвристики работают, но не полиномиально
        
    
    
    
        Машинное обучение в математике
        
        
            AlphaProof (DeepMind, 2024)
            Neural network + formal verification для решения олимпиадных задач
        
        
        Применения:
        
            Предсказание гипотез — нейросети находят паттерны в данных
            Генерация доказательств — LLM создают кандидатов
            Оптимизация — RL находит лучшие стратегии
            Классификация — CNN различают типы задач

        Оптимизация вычислений
        
        Кэширование
        
        Проблема: ζ(s) вычисляется многократно
        Решение: Кэш по s = σ + it
        
        Ключ: (σ, round(it, 10))
        Значение: ζ(s)
        Экономия: 10x ускорение
        
        
        Параллелизация
        
        Задача: 10^13 нулей Римана
        Метод: Map-Reduce
        
        Map: каждый узел проверяет свой диапазон
        Reduce: сборка результатов
        
        Ускорение: N узлов → N-кратное
        
        
        Предвычисление
        
        Задача: Повторные вычисления ζ(s)
        Метод: Табличный метод
        
        Таблица: 10^6 значений
        Интерполяция: сплайн
        Точность: 10^-15
        
    
    
    
        Пример: Генетический алгоритм для SAT
        
        
        // Генетический алгоритм для 3-SAT
        
        population = random_assignments(1000)
        
        for generation in range(10000):
            // ОценкаFitness
            fitness = [count_satisfied(clause, ind) for ind in population]
            
            // Отбор
            parents = tournament_select(population, fitness, 100)
            
            // Скрещивание
            children = crossover(parents, 500)
            
            // Мутация
            children = mutate(children, 0.01)
            
            // Замена
            population = elitist_replace(population, children, fitness)
        
        best = max(population, key=fitness)
        
        
        
            Результат
            Для 3-SAT с 1000 переменных:
            
                Полный перебор: 2^1000 операций (невозможно)
                Генетический: 10000 × 1000 = 10^7 операций
                Ускорение: 10^(300) раз
            
        
    
    
    
        Барьеры вычислений
        
        
            Экспоненциальный взрыв
            Даже суперкомпьютеры не справляются с задачами размером > 10^20 операций.
        
        
        
            Парадокс кривой обучения
            Чем сложнее задача, тем труднее подобрать гиперпараметры.
        
        
        
            Проблема обобщения
            Нейросеть, обученная на одном типе задач, может не работать на другом.
