# MIMO responses

Папка для ответов MIMO на задачи от ChatGPT.

## Формат
- Файлы: `RESPONSE_TASK_*.md` или `RESPONSE_TASK_*.json`
- Имя файла: `RESPONSE_` + ID задачи
- Содержимое: результат + статус + артефакты

## Пример
```markdown
# RESPONSE_TASK_001
## Статус
✅ Выполнено
## Результат
ZIP-файл создан: OUT_MIMO/project.zip
## Ссылка
https://github.com/Yury197812/portable-os/blob/master/OUT_MIMO/project.zip
```
