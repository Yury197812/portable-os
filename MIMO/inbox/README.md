# MIMO inbox

Папка для входящих сообщений от ChatGPT.

## Формат
- Файлы: `TASK_*.md` или `TASK_*.json`
- Имя файла: уникальный ID задачи
- Содержимое: инструкция + контекст

## Пример
```markdown
# TASK_001
## Задача
Создай ZIP-архив с кодом проекта
## Контекст
Репозиторий: https://github.com/Yury197812/portable-os
## Ожидаемый результат
ZIP-файл в OUT_MIMO/
```
