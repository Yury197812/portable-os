🚀 Portable OS

Портабельная операционная система с доступом в интернет

📦 Содержимое пакета

⚙️engine/

Ядро системы: управление процессами, памятью, файловой системой

core.js

💻terminal/

Терминал с основными командами

shell.js commands.js

📁filesystem/

Виртуальная файловая система на USB

vfs.js mount.js

🌐network/

Безопасный доступ в интернет

proxy.js dns.js

🔧skills/

Модульная система навыков

github-login

📊dashboard/

Визуальный интерфейс

UI

├── boot/           # Direction 1: System Boot

│   ├── init.js
│   └── config.js
├── terminal/       # Direction 2: Terminal
│   ├── shell.js
│   ├── commands.js
│   └── history.js
├── filesystem/     # Direction 3: File System
│   ├── vfs.js
│   ├── mount.js

│   ├── proxy.js
│   ├── dns.js

├── skills/         # Skill system
├── api/            # API layer
├── dashboard/      # UI
└── portable/       # USB packaging
