# Portable OS

Portable PO with internet access.

## Quick Start

```bash
npm install
npm start
```

## Structure

- `app/` — Terminal, filesystem, network modules
- `engine/` — Core system
- `skills/` — Skill modules
- `book/` — Development documentation
- `tests/` — Test suite
