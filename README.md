# Portable OS

Portable PO with internet access.

## Structure

- `app/` - Application layer
- `engine/` - Core engine
- `skills/` - Skill modules
- `book/` - Oculus book project
- `MIMO/` - MIMO integration
- `tests/` - Test suite
- `build/` - Build scripts
- `portable/` - Portable distribution
- `dashboard/` - Dashboard UI
- `api/` - API layer
