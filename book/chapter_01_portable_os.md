# Глава 1. Введение в Portable OS

## 1.1 Что такое Portable OS

Portable OS — это операционная система, которая работает с любого носителя без установки на жесткий диск. Она предназначена для:

- Работы на чужих компьютерах без следов
- Безопасного доступа к интернету
- Переноса рабочей среды с собой

## 1.2 Архитектура системы

```
┌─────────────────────────────────────┐
│           Dashboard (UI)            │
├─────────────────────────────────────┤
│           App Layer                 │
├─────────────────────────────────────┤
│           Engine Core               │
├─────────────────────────────────────┤
│           Skills System             │
├─────────────────────────────────────┤
│           API Layer                 │
├─────────────────────────────────────┤
│           Portable Runtime          │
└─────────────────────────────────────┘
```

## 1.3 Компоненты системы

### app/ — Слой приложений
Базовые приложения: браузер, файловый менеджер, терминал.

### engine/ — Ядро системы
Управление процессами, памятью, файловой системой.

### skills/ — Система навыков
Модульная система расширения возможностей.

### api/ — API слой
Интерфейсы для взаимодействия компонентов.

### dashboard/ — Панель управления
Визуальный интерфейс пользователя.

### portable/ — Переносимый контейнер
Скрипты загрузки и конфигурация для USB-носителей.

## 1.4 Первый цикл разработки

В рамках первого цикла мы реализуем:
1. Базовую загрузку системы
2. Терминал с основными командами
3. Файловую систему
4. Подключение к интернету

## 1.5 Требования

- Node.js 18+
- Python 3.10+
- USB-носитель 8GB+ (для переноса)
